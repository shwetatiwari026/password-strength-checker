# password-strength-checker
- A simple password strength checker using Python and Streamlit

## Technologies Used
- Python
- Streamlit
- Regular Expressions (re)

### Features
- Checks password length
- Checks uppercase letters
- Checks lowercase letters
- Checks numbers
- Checks special characters
- Shows password score
- Gives suggestions to improve password strength
